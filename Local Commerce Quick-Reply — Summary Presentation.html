Key Technical Decisions

  • Prompt Stuffing 100% (ไม่ใช้ Vector DB) — สินค้า 10–50 รายการ ตัด Embedding Pipeline
  • Deterministic Logic สำหรับตัวเลข — ราคา/ค่าส่ง/ยอดรวม ดึงจากตารางแล้วคำนวณด้วยโค้ด
  • ngrok สำหรับ Local Dev — ทดสอบ Webhook ได้ทันทีไม่ต้อง deploy
